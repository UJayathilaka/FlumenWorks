# Fulmen Works

Five free Chrome extensions by Udantha Jayathilaka (U Jay) that take the repeated clicks out of product data work.

| Tool | Version | What it does |
|---|---|---|
| GXS Product Uploader | v8.17.5 | Batch-uploads product images on graphxserver PDB |
| PDF Layer Viewer | v1.12.0 | Shows every PDF layer and switches each on or off |
| Image Downloader & Zipper | v5.4 | Turns pasted image links into one sorted ZIP |
| Mapper Toolkit | v2.2.5 | Copies rows and speeds up product dialogs |
| Master Quality Checker | v2.104.3 | Makes PDB links, runs the Master Check, verifies images |

Live site: https://udanthajayathilaka.github.io/FlumenWorks/
